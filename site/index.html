Four to start with

Or describe one

/theme create hands your description to the model, which designs the palette and the animation together. You review it before it is written anywhere.

1

Say what you want

A mood is enough. These are the examples the prompt box offers:

  • cyberpunk thunderstorm
  • moody vampire castle
  • autumn library at dusk
  • sakura in moonlight
  • phosphor terminal, 1984
  • sunlit sea glass
2

Watch it before you keep it

The draft is registered live and previewed two ways — the backdrop animating at full size, and a scripted session that exercises about fifteen colour slots so you can see what real output looks like.

3

Change it in plain language

“slower”. “add drifting embers”. “calmer warnings”. Each refinement returns a delta, so anything you did not mention stays exactly as it was — and you can undo.

The renderer ships once; the model ships content. An animation is described entirely in the theme's JSON — layers, motion verbs, glyph catalogues, one arithmetic expression for rhythm. That is what lets a binary you installed from npm produce an animation nobody wrote into it. Nothing in a theme file is ever executed: no eval, no Function, no property access — just a hand-written parser with hard caps and a fuzz test.
